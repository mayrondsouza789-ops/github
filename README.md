# Website projects

[ProgressCheck working demo](./progresscheck/).

ProgressCheck includes photo check-ins, real on-device experimental hair segmentation, saved records, reports, and a mock reviewer workflow. See its [setup instructions](./progresscheck/README.md) to run it. [Open the live ProgressCheck demo](https://progresscheck.vercel.app). Anyone can open the public guest demo without an account. Guest records stay in that browser; optional Supabase sign-in uses a separate account workspace with persistent records. The source includes verified setup for its model and runtime assets.
